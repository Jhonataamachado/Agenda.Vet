# 🐾 Sistema de Agendamento Veterinário

Aplicação web desenvolvida em Python para clínicas veterinárias com integrações nativas de comunicação.

## 🚀 O Problema que Resolve
Simplifica a marcação de consultas e a notificação de tutores. O sistema gera links dinâmicos que preparam mensagens automáticas de confirmação no WhatsApp e adicionam o evento diretamente ao Google Calendário, eliminando trabalho administrativo manual.

## 💻 Tecnologias
* Python & Streamlit: Lógica de negócio e construção da interface de utilizador.
* URL Parsing: Integração direta com WhatsApp Web e Google Calendar sem dependência de APIs pagas.
